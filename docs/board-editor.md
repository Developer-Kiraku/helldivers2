# 게시판 본문 편집

모든 게시판의 작성·수정 화면에 MIT 라이선스의 무료 오픈소스 Tiptap 3 에디터를 사용합니다. 유료 확장이나 외부 편집 서비스는 사용하지 않습니다.

- **HTML 소스**에서 HTML을 입력한 후 **일반 편집**으로 확인합니다. 소스 모드에서 바로 저장해도 반영됩니다.
- 글자를 선택하고 크기 목록에서 선택하면 즉시 적용합니다. 12~72px의 정수 크기를 1px씩 지정할 수 있고 현재 선택한 글자의 크기를 표시합니다. 실행 취소·다시 실행도 지원합니다.
- **유튜브**에 일반 영상·단축 링크·Shorts·라이브 주소를 넣습니다. 유튜브 URL 하나만 본문에 붙여넣어도 영상으로 바뀝니다. 링크에 포함된 시작 시간을 유지하며 자동 재생은 사용하지 않습니다.
- 본문 첨부·이미지 붙여넣기·사진 게시판은 가로 1,600px를 초과하면 비율을 유지해 축소·압축합니다. 원본은 JPG·PNG·WebP, 최대 20MB입니다. 프로필은 최대 256px 정사각형으로 저장합니다. HTML의 HTTPS 이미지 URL도 사용할 수 있으며 외부 URL의 원본 파일은 변경하지 않습니다. 서버에서도 업로드 이미지의 형식·해상도를 검증하고 메타데이터를 제거합니다.

HTML 미리보기·붙여넣기는 DOMPurify로 정리하고, 서버에서도 sanitize-html로 다시 검증합니다. 허용된 본문 서식과 12~72px 글자 크기만 유지합니다. iframe은 검증된 유튜브 영상 ID로만 다시 구성하며 이벤트 속성, srcdoc, 임의 스크립트와 외부 iframe은 제거합니다.

유튜브에서 외부 재생을 제한한 영상은 재생되지 않을 수 있습니다.

## AI 내용 보정

AI 내용 보정은 현재 화면에서 임시 숨김 상태입니다. 다시 활성화하면 모든 게시판(헬스타그램 포함)에서 원문과 결과를 비교한 후 적용할 수 있습니다.

- 서버 환경 변수 `OPENAI_API_KEY`를 설정하고 서버를 재시작하세요. Render에서는 서비스의 Environment에 추가합니다. 키가 없으면 설정 안내가 표시됩니다.
- 모델은 `OPENAI_POLISH_MODEL`로 지정하며 기본값은 `gpt-4.1-mini`입니다. 호출 시 OpenAI API 사용료가 발생합니다.
- 제목과 본문 텍스트만 전송합니다. 이미지·영상·링크 주소와 서식은 전송하거나 변경하지 않습니다. 코드 블록은 보정에서 제외합니다. 본문 속에 직접 적은 URL은 텍스트에 포함됩니다.
- 본문 최대 10,000자, 회원별 10초 간격·시간당 20회로 제한합니다. 외부 API에 전송을 시도한 실패 요청도 횟수에 포함됩니다. 감사 로그에는 회원·게시판·시간만 기록하며 원문과 결과를 기록하지 않습니다.
- 자동 저장하지 않습니다. AI가 의미나 게임 용어를 잘못 바꿀 수 있으므로 적용 전에 결과를 확인합니다.

연동은 [OpenAI 공식 Structured Outputs 문서](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)를 따릅니다. 검증: `node scripts/test-ai-polish.mjs`.

검증: `node scripts/test-tiptap.mjs`, `node scripts/test-post-html.mjs`, `npm run test:functional`. 기능 테스트는 격리된 DB에서 HTML·영상·글자 크기 저장/수정 및 위험한 HTML 제거를 확인합니다.

공식 프로젝트와 라이선스: https://github.com/ueberdosis/tiptap
