# 게시판 본문 편집

모든 게시판의 작성·수정 화면에 MIT 라이선스의 무료 오픈소스 Tiptap 3 에디터를 사용합니다. 유료 확장이나 외부 편집 서비스는 사용하지 않습니다.

- **HTML 소스**에서 HTML을 입력한 후 **일반 편집**으로 확인합니다. 소스 모드에서 바로 저장해도 반영됩니다.
- 글자를 선택하고 크기 목록에서 선택하면 즉시 적용합니다. 12~72px의 정수 크기를 1px씩 지정할 수 있고 현재 선택한 글자의 크기를 표시합니다. 실행 취소·다시 실행도 지원합니다.
- **유튜브**에 일반 영상·단축 링크·Shorts·라이브 주소를 넣습니다. 유튜브 URL 하나만 본문에 붙여넣어도 영상으로 바뀝니다. 링크에 포함된 시작 시간을 유지하며 자동 재생은 사용하지 않습니다.
- 본문 이미지는 파일 삽입 외에 HTML의 HTTPS 이미지 URL도 사용할 수 있습니다. 프로필 사진의 업로드 규칙은 그대로입니다.

HTML 미리보기·붙여넣기는 DOMPurify로 정리하고, 서버에서도 sanitize-html로 다시 검증합니다. 허용된 본문 서식과 12~72px 글자 크기만 유지합니다. iframe은 검증된 유튜브 영상 ID로만 다시 구성하며 이벤트 속성, srcdoc, 임의 스크립트와 외부 iframe은 제거합니다.

유튜브에서 외부 재생을 제한한 영상은 재생되지 않을 수 있습니다.

검증: `node scripts/test-tiptap.mjs`, `node scripts/test-post-html.mjs`, `npm run test:functional`. 기능 테스트는 격리된 DB에서 HTML·영상·글자 크기 저장/수정 및 위험한 HTML 제거를 확인합니다.

공식 프로젝트와 라이선스: https://github.com/ueberdosis/tiptap
