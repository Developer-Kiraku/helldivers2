# 게임 결과 공유와 스트라타젬 히어로

## 결과 공유

슬라이딩 퍼즐, 민주주의 주사위, 가위바위보, 스트라타젬 히어로의 완료 화면에서 결과를 공유합니다. 주사위는 다음 판이 자동 시작되어도 최근 종료한 게임을 공유할 수 있으며, 이미 연 공유 레이어는 처음 선택한 판을 유지합니다.

손 강화 팝업의 **내 손 강화 공유**도 같은 PNG 저장·파일 공유·카카오톡 공유를 사용합니다. `rps-hand` 결과는 서버에 저장된 본인의 현재 손 단계·이름·닉네임으로 생성하며, 강화 버전이 화면과 다르면 다시 열도록 안내합니다. 0강과 최고 단계도 공유할 수 있습니다. 이미 만든 카드의 수치는 이후 강화 성공·실패에 따라 바뀌지 않습니다. 공유용 손 문양은 강화 팝업과 같은 SVG를 사용합니다.

- `POST /api/games/share`는 로그인·Origin 검증 후 본인의 완료된 서버 기록만 조회합니다. 클라이언트에서 보낸 점수·이름·보상은 받지 않습니다. 같은 회원/게임/결과에 대해서는 같은 공유 ID를 반환합니다.
- 총운영자처럼 랭킹에서 제외된 회원도 자신의 결과를 공유할 수 있습니다. 슬라이딩 퍼즐의 저장된 개인 최고 기록에도 공유 버튼을 제공합니다.
- 스트라타젬 히어로의 상태 조회는 시간 초과로 끝난 결과를 저장합니다. 이전에 화면만 종료되고 서버에 진행 중으로 남은 기록도 본인이 공유하면 서버 제한 시간을 확인해 종료 처리합니다. 진행 중인 게임이나 다른 회원의 기록은 공유할 수 없습니다.
- 공유 버튼을 누른 경우에만 `gameShares`에 최소 결과 스냅샷을 저장합니다. 원래 게임 기록이 정리되어도 링크는 유지됩니다. 닉네임, 게임 결과, 완료 시각만 공개하며 회원 ID, 보유 포인트, 세션, 상대 회원의 닉네임을 포함하지 않습니다.
- `/game-results/{24자리 난수}`와 하위 `/image`는 공유를 위해 공개하는 유일한 새 페이지/이미지입니다. 다른 게임·게시판의 로그인 제한은 그대로입니다. 검색 노출을 막고, 탈퇴한 회원의 공유는 반환하지 않습니다.
- 결과 PNG는 서버가 1200×630으로 만듭니다. 한국어 글꼴은 기존 Pretendard의 OFL 라이선스를 유지하고 예약 이름을 피한 정적 `HDGameResult.woff`를 사용합니다.
- 파일 공유가 가능한 브라우저에서는 **이미지 공유**로 시스템 공유 창을 열 수 있습니다. 특정 앱을 강제로 선택할 수는 없습니다. PNG 다운로드도 제공합니다.
- **카카오톡 공유**는 기존 SETTING의 JavaScript 키와 SDK를 사용합니다. `scrapImage`로 이미지를 준비하고 `sendDefault`로 이미지 카드와 결과 링크를 보냅니다. 이미지 준비 실패 시 텍스트와 결과 링크로 공유하며, SDK 연결 실패 시에도 다운로드·URL 복사를 사용할 수 있습니다. 실제 전송은 사용자가 카카오 공유 창에서 수신자를 선택해야 합니다.

참고: [카카오 공유](https://developers.kakao.com/docs/ko/kakaotalk-share/js-link), [이미지 스크랩·메시지 SDK](https://developers.kakao.com/sdk/reference/js/release/Kakao.Share.html), [Next ImageResponse](https://nextjs.org/docs/app/api-reference/functions/image-response).

## 스트라타젬 히어로 도전 단계

10단계는 기본 최종 단계이며 2,000P를 받고 종료하거나 도전을 계속할 수 있습니다. 11~15단계는 각각 명령 16/17/18/19/20개, 제한 시간 25초, 총 지급액 4,000/8,000/16,000/32,000/64,000P입니다. 15단계만 자동 정산합니다. 기존 도중 실패 시 무보상 규칙과 100P 참가비는 유지하며, 배포 전에 시작한 게임은 저장된 단계 설정을 따릅니다.

`stratagemRecords`에 회원별 최고 기록을 저장합니다. 단계가 높은 순 → 해당 단계까지 누적 클리어 시간이 짧은 순 → 먼저 달성한 순으로 정렬합니다. 각 단계의 서버 시작부터 마지막 정답 수신까지 합산하므로 단계 사이 보상 선택 시간은 제외됩니다. 단계 성공 즉시 기록하여 나중에 실패해도 이미 성공한 기록이 남습니다. 기존 기록에는 단계별 측정값이 없어 새 도전부터 집계합니다. 총운영자 등 순위 제외 회원은 별도 영역, 테스트 계정은 랭킹에서 제외됩니다.

PostgreSQL의 `hd_game_shares`, `hd_stratagem_records`는 기존 자동 마이그레이션을 사용합니다. 게임 요청은 필요한 컬렉션만 읽고, 공유 이미지에는 작은 메모리 캐시를 둡니다.

대시보드는 포인트·월별 퍼즐·현재 손 강화·스트라타젬 히어로 랭킹을 각각 5명씩 더보기로 표시합니다. 손 강화는 1강 이상인 활성 회원의 현재 단계순이며, 같은 단계는 닉네임·회원 ID순입니다. 히어로는 게임 페이지와 같은 최고 기록 정렬을 사용합니다. 두 랭킹 모두 총운영자 기록은 별도로 표시하고 테스트 회원·탈퇴 회원은 제외합니다.

검증: `test-game-shares.mjs`, `test-game-share-ui.mjs`, `test-game-shares-http.cjs`, `test-stratagem-share-http.cjs`, `test-stratagem-challenge.mjs`, `test-stratagem-rankings.mjs`, 기존 게임 UI·HTTP 회귀 테스트. 전체 검증은 `npm run test:functional`에 포함됩니다.
