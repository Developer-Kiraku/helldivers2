# 카카오톡 공유

모든 게시판의 게시글 상세 및 헬다이버톡·질문상담실 피드의 **공유** 버튼에서 카카오톡 공유와 URL 복사를 제공합니다.
Render에서는 `/s/16자리코드` 주소를 사용합니다. 코드가 동일 게시글에 대해 유지되며, 게시글을 삭제하면 링크도 404가 됩니다. 로그인 전에는 제목과 최대 120자의 본문 요약을 포함한 Open Graph/Twitter 미리보기 HTML을 반환합니다. 일반 브라우저는 로그인 화면으로 이동하며 로그인 후 원래 게시글을 엽니다. JavaScript가 꺼져 있으면 로그인 링크를 사용할 수 있습니다. 외부 단축 URL 서비스를 사용하지 않습니다.

공개 JavaScript 키는 `src/lib/kakao-share.js`에서 설정합니다. 이 키는 브라우저 공유용이며 카카오 로그인용 `KAKAO_REST_API_KEY`와 다릅니다.

## 카카오 Developers 필수 설정

해당 앱에서 아래 두 곳에 `https://helldivers2.onrender.com`을 등록하세요.

1. 앱 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인
2. 앱 → 제품 링크 → 웹 도메인

로컬 테스트에는 `http://localhost:3000`, GitHub Pages 미리보기에는 `https://developer-kiraku.github.io`도 각각 등록해야 합니다. Pages는 정적 미리보기이므로 `/s/` 서버 경로 대신 해시 라우터 주소를 공유합니다.

SDK는 공유 창을 열 때만 로드합니다. 카카오 연결이 실패해도 URL 복사는 사용할 수 있습니다. 공유 창과 카카오 메시지에는 게시글 제목, 공백을 정리한 최대 120자의 본문 요약, 공용 대시보드 이미지, 링크를 표시합니다. 본문 전체와 작성자·회원 정보·첨부 이미지는 공개 미리보기에 포함하지 않습니다. 이미지·영상만 있는 게시글에는 안내 문구를 표시합니다. URL 미리보기의 갱신 시점은 공유 서비스의 캐시에 따라 달라질 수 있습니다.

참고: https://developers.kakao.com/docs/ko/kakaotalk-share/js-link

PC에서는 SDK의 `sendDefault()`가 카카오 웹 공유창을 열고 `sharer.kakao.com`으로 폼을 전송합니다. 따라서 CSP `form-action`에 공식 공유 도메인 `https://sharer.kakao.com`을 허용합니다. 기존 로그인용 `kauth.kakao.com` 허용도 유지합니다. 공유 버튼의 클릭 이벤트에서 동기적으로 SDK를 호출하여 팝업에 필요한 사용자 제스처를 유지합니다.

모바일에서는 카카오톡 공유 버튼을 항상 표시하며 SDK 로딩 중·실패 시에는 비활성화하고 재시도를 제공합니다. PC에서는 SDK 공유 함수와 브라우저의 팝업 API를 사용할 수 있을 때만 같은 노란 디자인의 **카카오톡 공유 (PC)** 버튼을 표시합니다. PC SDK 연결 실패 시에도 URL 복사는 사용할 수 있습니다. 실제 팝업 차단 설정과 카카오계정 로그인 상태는 브라우저 설정에 따릅니다.
