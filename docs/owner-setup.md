# 운영 시작 계정 정리

Render Shell에서 운영 DB의 카카오 인증 기록과 계정을 먼저 확인합니다.

```sh
node scripts/manage-owner.mjs inspect
node scripts/manage-owner.mjs plan VERIFIED_KAKAO_MEMBER_ID 닉네임
```

리뷰한 계획이 맞을 때만 `plan`을 `apply`로 바꿔 실행합니다. API 키가 아닌 카카오 회원 식별자를 사용하며, 이미 실제 인증 기록이 있는 특정 계정만 지정할 수 있습니다. 요청자가 로그인할 때 임의의 첫 계정에 운영권을 주는 기능은 없습니다.

`apply`는 지정한 카카오 회원 하나를 `operator`(총운영자)로 만들고 기존 임시 4계정을 삭제합니다. 예상하지 못한 다른 실회원이 있으면 중단합니다. 게시글·댓글을 유지하며, 삭제된 작성자는 탈퇴한 회원으로 표시합니다. 기존 세션·가입 대기 티켓과 임시 계정의 투표·운영 요청은 정리합니다. 비밀번호 로그인은 만들지 않습니다.

모든 변경은 DB 트랜잭션 하나에서 처리합니다. 완료 기록이 있으면 재실행을 거부하며, 이후 가입하는 일반 회원에게 영향을 주지 않습니다. 가입 약관 동의 기록을 임의로 생성하지 않습니다.

카카오 인증 후 리다이렉트는 `APP_ORIGIN`(Render: `https://helldivers2.onrender.com`)을 사용합니다. Next.js 내부 바인딩 주소 `0.0.0.0:10000`을 브라우저로 보내지 않습니다.
