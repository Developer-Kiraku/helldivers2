# 전쟁 채권 사전 데이터 관리

작성 화면 없이 다음 자료를 수정해 채권을 추가합니다.

- `src/lib/warbond-catalog.mjs`: 채권 가격, 실제 게임 페이지 순서, 페이지별 보상과 메달 가격.
- `src/lib/warbond-rewards.mjs`: 기존 장비 목록에 없는 방어구 세트·헬멧·망토·꾸미기·재화.
- `src/lib/equipment-catalog.mjs`: 무기·스트라타젬·부스터와 채권 표지의 공용 원본. 사전에서는 `equipmentId`로 참조하므로 기존 이름이나 아이콘 변경이 함께 적용됩니다.
- `public/warbonds/`: 추가 보상 이미지. 출처의 실제 게임 이미지를 WebP로 최적화해 저장합니다.
- `sources.json`: 대조 날짜, 출처, 확인한 메달 총액, 이미지 원본 주소 및 한글명을 확인하지 못한 항목.

추가할 때는 채권의 표지 ID를 공용 장비 목록에 등록하고, 사전의 고유한 `slug` 및 페이지별 보상을 추가합니다. 방어구의 실제 장비 보상은 `suit`로 등록합니다. 방어구 옵션 아이콘으로 장비 이미지를 대체하지 않습니다. 슈퍼 크레딧은 공용 보상 ID `super-credits`에 `amount`를 지정합니다.

페이지별 이름·가격·구성은 출처와 대조하며, 확인되지 않은 한글 이름을 임의로 번역하지 않습니다. 현재 일부 공성 파괴자 꾸미기 보상은 확인된 영문명을 유지합니다.

확인 명령: `node scripts/test-warbonds.mjs`. 화면과 접근 권한까지 확인하려면 빌드한 뒤 `npm run test:functional`을 실행합니다.
