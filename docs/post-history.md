# 게시글 수정·삭제 이력

운영자와 부운영자는 **운영 관리 → 게시글 변경 이력**(`/admin/post-history`)에서 작업 종류·게시판·제목·작업자로 검색하고 상세 이력을 확인할 수 있습니다. 일반회원·견습회원·비로그인 사용자는 페이지와 API에 접근할 수 없습니다.

일반 게시글 수정, 본인·운영자 직접 삭제, 운영자 승인에 따른 삭제를 기존 `audit` 컬렉션/`hd_audit` 테이블에 보관합니다. 작업과 로그는 같은 트랜잭션에서 저장하므로 실패한 수정·삭제는 이력을 남기지 않습니다. 작업자 당시 닉네임·등급, 작업 시각, 게시판, 제목, 변경 항목, 수정 전후 텍스트, 분류, 첨부 이미지 장수·해시, 영상 URL, 상단 고정 여부를 저장합니다. 삭제 로그에는 삭제 당시 내용·사유를, 승인 삭제에는 요청자도 기록합니다. 본문 서식과 이미지 변경 여부는 SHA-256으로 식별하며 이미지 원본과 HTML 원문을 중복 저장하지 않습니다. 시간은 한국 시간으로 표시합니다.

목록 API는 `GET /api/admin/post-history?action=&board=&q=&page=`이며 페이지당 20건의 요약만 반환합니다. 상세 API는 `GET /api/admin/post-history/{로그ID}`입니다. 상세 내용은 HTML을 실행하지 않고 텍스트로 표시합니다. 화면에서 삭제된 글의 이력도 조회할 수 있지만 이력 변경·삭제 API는 제공하지 않습니다.

기존 수정·삭제 로그도 목록에 표시합니다. 과거 로그에는 당시 본문이 없으므로 현재 본문을 과거 내용으로 대신 표시하지 않으며, 상세 화면에 기록이 없는 이유를 안내합니다. 상세 스냅샷은 이 기능 적용 이후 작업부터 남습니다. 별도 DB 마이그레이션은 필요하지 않습니다.
