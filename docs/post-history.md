# 로그 확인

운영자·부운영자는 **운영 관리 → 로그 확인**(`/admin/logs`)에서 게시글 수정·삭제, 회원 가입·탈퇴를 분류별로 확인합니다. 일반회원·견습회원·비로그인 사용자는 페이지와 API에 접근할 수 없습니다. 이전 `/admin/post-history` 주소는 새 화면으로 이동합니다.

큰 카드와 상세 비교창 대신 실행 일시, 실행한 유저 닉네임, 글 제목 또는 회원 닉네임, 글 작성일 또는 회원 가입일을 한 줄에 표시합니다. 시간은 한국 시간이며 최근순으로 페이지당 10건을 보여줍니다. 분류 필터와 제목·닉네임 검색을 제공하고, 좁은 화면에서는 표 내부를 가로 스크롤할 수 있습니다.

목록 API는 `GET /api/admin/logs?type=&q=&page=`입니다. 분류는 `post_update`, `post_delete`, `member_join`, `member_leave`입니다. 승인 후 삭제는 게시글 삭제에, 견습 기간 만료에 따른 자동 탈퇴는 회원 탈퇴에 포함합니다. 자동 탈퇴는 실행 유저를 ‘시스템’으로 표시합니다. 응답에는 목록 표시용 필드만 포함하며 본문·회원 인증 정보·이미지 원본은 반환하지 않습니다.

수정·삭제 기록과 기존 스냅샷 저장은 유지합니다. 가입·탈퇴 시에는 당시 닉네임과 가입일도 함께 기록하여 탈퇴 처리나 이후 닉네임 변경으로 로그 표시가 바뀌지 않도록 합니다. 작업과 로그는 같은 트랜잭션에서 저장하므로 실패한 작업은 남지 않습니다. 기존 `audit` 컬렉션/`hd_audit` 테이블을 사용하며 별도 DB 마이그레이션은 필요하지 않습니다. 과거 기록에 닉네임이 없고 이미 탈퇴 처리된 경우 원래 닉네임을 복원하지 않고 ‘탈퇴한 회원’ 또는 ‘정보 없음’으로 표시합니다.
