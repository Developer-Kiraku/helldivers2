HDGameResult.woff is a static weight-600 instance of the same font, generated
with fontTools for the server-rendered game result PNG (Satori supports WOFF, not WOFF2).
Its internal family name is HDGameResult, respecting the reserved font name.
It retains the original font license and is loaded locally by the image renderer.
