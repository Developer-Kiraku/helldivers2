# 헬다이버즈2 커뮤니티 · Next.js / React

승인된 디자인에 서버 로그인·회원 관리·게시판·운영진 처리 요청을 연결한 실행 가능한 프로젝트입니다. `DATABASE_URL`이 있으면 PostgreSQL을 사용하며, 미설정 시 기존 서버 JSON 파일을 사용합니다.

## GitHub Pages 디자인 미리보기

[미리보기 열기](https://developer-kiraku.github.io/helldivers2/)

화면 확인만 가능한 정적 버전입니다. 기존 React 화면을 사용하며 상단에서 운영자·부운영자·일반·견습·로그인 전 화면을 전환할 수 있습니다. 로그인·가입·프로필·게시판·회원 관리·요청 화면과 PC/모바일 디자인을 확인할 수 있습니다. 표시하는 모든 계정·게시글·요청은 예시이며 실제 카카오 인증·데이터 변경·저장은 실행하지 않습니다.

`npm run build:pages`로 `pages-dist`를 생성합니다. `preview/`와 `scripts/build-pages.mjs`가 전용 진입점이며 Next.js 서버용 소스·실제 DB·환경변수는 정적 배포에 포함하지 않습니다. 주소의 `#/...` 부분으로 화면을 이동하므로 각 화면 링크를 그대로 공유하거나 새로고침해도 유지됩니다.

GitHub 설정은 **Settings → Pages → Source: GitHub Actions**입니다. `main`에 push하면 `.github/workflows/pages.yml`이 미리보기를 자동 갱신합니다. 실제 기능 서비스는 아래의 Next.js 실행 방법을 사용합니다.

## 실행

```bash
npm ci
```

`.env.example`을 `.env.local`로 복사한 뒤 다음 명령으로 실행합니다.

```bash
npm run dev
```

기본 주소는 `http://127.0.0.1:3000`입니다. Node.js 20.9 이상이 필요합니다. 배포용 실행 및 통합 검증:

```bash
npm run build
npm run test:functional
npm run test:probation
npm run start
```

## 임시 계정

| 등급 | 아이디 | 비밀번호 | 닉네임 |
| --- | --- | --- | --- |
| 운영자 | admin | 1234 | 라미아 |
| 부운영자 | subadmin | 1234 | 부운영자 |
| 일반회원 | user1 | 1234 | 헬다이버 |
| 견습회원 | user2 | 1234 | 견습헬다이버 |

회원 필드는 카카오 로그인 식별자, 등급, 닉네임, 프로필 사진, 최근 로그인, 생성일을 포함합니다. 임시 계정의 카카오 정보는 ‘미연결’로 표시됩니다. 외부 서비스로 전환할 때 `DEMO_AUTH_ENABLED=false`로 임시 계정 로그인을 끕니다.

## 화면과 접근

| 주소 | 기능 |
| --- | --- |
| `/login` | 카카오 로그인 및 임시 계정 로그인 |
| `/signup` | 카카오 인증 후 서비스 필수 동의·닉네임 가입 |
| `/` | 게시판별 최신글 5개, 로그인 세션 인원·총 회원 수·한국 현재 시각 |
| `/profile` | 사진·닉네임 변경, 회원 정보, 탈퇴 |
| `/boards/{notice,guide,talk}` | 공지·공략 목록, 헬다이버톡 피드 |
| `/boards/helstagram` | 헬스타그램 사진 피드, 사진 넘기기·댓글·추천 |
| `/boards/{board}/{id}` | 본문·댓글·추천/비추천·게시글 관리 |
| `/boards/{board}/write` | 게시글 작성, 링크·본문 이미지 삽입 |
| `/boards/{board}/{id}/edit` | 본인 게시글 수정 |
| `/admin/users` | 운영진 회원 리스트, 운영자 등급 변경·강퇴, 부운영자 강퇴 요청 |
| `/admin/approvals` | 요청 승인 목록: 내 권한으로 처리할 수 있는 가입·삭제·강퇴 요청 및 이력 |

로그인 전에는 로그인·회원가입 페이지만 볼 수 있습니다. 로그인 후 로그인·회원가입 주소는 메인으로 이동합니다. 서버 페이지 및 API에서 인증·권한을 검사합니다. 실제 회원 상태는 계정으로 로그인해 확인하며 상단에는 PC/모바일 미리보기 전환만 남겼습니다.

공지 작성은 운영자·부운영자만 가능합니다. 모든 등급은 공략·톡 작성 및 본인 글 수정·삭제가 가능합니다. 운영자는 하위 등급 글을 직접 삭제하고 하위 회원을 강퇴할 수 있습니다. 부운영자는 일반·견습회원의 글 삭제·강퇴를 요청하며 운영자 승인 후 실행됩니다. 처리 사유·시각·담당자와 감사 기록을 JSON에 저장합니다.

견습회원은 가입 후 한 달 안에 운영자·부운영자의 승인을 받아야 합니다. 요청 승인 목록에서 승인하면 일반회원으로 전환되며 미승인 만료 계정은 자동 탈퇴됩니다. 운영자에게는 가입·삭제·강퇴 요청이, 부운영자에게는 가입 승인 요청이 표시됩니다. 기한은 한국 시간 달력 한 달(말일 보정)이고 서버 시작·매 1분·데이터 요청 전에 검사합니다. 서버가 멈춰 있으면 재가동 시 처리합니다. 회원 리스트와 내 정보에 기한을 표시합니다.

## 실제 카카오와 데이터 연결

헬스타그램은 로그인한 모든 회원이 사진을 1~10장씩 올리는 게시판입니다. 여러 사진을 한 번에 선택하고 순서를 바꾸거나 삭제할 수 있습니다. JPG·PNG·WebP(사진당 최대 20MB)를 가로 1,600px 초과 시 비율을 유지해 자동 축소·압축합니다. 본문 첨부·클립보드 이미지에도 같은 처리를 적용하고, 프로필 사진은 최대 256px 정사각형으로 저장합니다. 서버에서도 이미지 형식과 크기를 검증하고 메타데이터를 제거합니다. 제목은 필수이고 설명은 선택입니다. 피드와 상세 화면에서 화살표·사진 선택 버튼·키보드 방향키·모바일 스와이프로 사진을 넘길 수 있습니다. 기존 댓글·추천·수정·삭제·운영진 권한과 JSON/PostgreSQL 저장소를 사용합니다.

`.env.local`에 `KAKAO_REST_API_KEY`, `KAKAO_CLIENT_SECRET`, `KAKAO_REDIRECT_URI`를 채우고 카카오 앱 도메인·콜백 주소를 등록하면 서버 인가 코드 교환 → 사용자 확인 → 가입/로그인을 실행합니다. 키 미설정 상태에서는 가입 계정을 임의로 만들지 않습니다. 신규 카카오 회원은 견습회원으로 가입합니다.

PostgreSQL 초기화는 `npm run db:migrate`, 비어 있는 DB로 기존 JSON 이전은 `npm run db:import -- data/db.json`입니다. [Render 배포·로컬 DB 연결 문서](docs/render-postgres.md)를 참고하세요. JSON 모드의 기본 경로는 `data/db.json`이며 `JSON_DB_FILE`로 바꿀 수 있습니다. JSON 모드는 단일 프로세스와 영구 디스크를 사용하는 임시 저장소입니다.

설정·데이터 구조·권한·카카오 연결 범위·검증 방법은 [docs/runtime.md](docs/runtime.md)에 정리했습니다. 약관·개인정보 문구는 운영 내용 확정 전 초안이며 [docs/legal-review.md](docs/legal-review.md)를 참고합니다.

## 코드 구성

- `src/app/(auth)`, `(protected)`: 로그인 전/후 페이지 분리.
- `src/app/api`: 로그인·가입·회원·게시판·관리 API.
- `src/lib/server`: 세션·비밀번호·입력 검증·JSON 저장소.
- `src/lib/roles.js`: 회원 등급과 순서.
- `src/lib/data.js`: 게시판 분류 및 최초 예시 글.
- `src/lib/community-links.js`: 디스코드·카카오 오픈채팅 주소.
- `src/components/CommunityProvider.jsx`: 서버 데이터와 UI 상태 연결.
- `scripts/test-functional.cjs`: 독립 JSON을 쓰는 통합 테스트.
- `public/images`: 승인된 4인 SD 배너 및 공식 로고.

## 공통 UI와 회원 관리

버튼·링크형 버튼·텍스트/비밀번호/검색 입력·선택창·체크박스·텍스트 영역·라벨·모달은 [Radix UI Themes](https://www.radix-ui.com/themes/docs/overview/getting-started)를 사용합니다. `src/components/ui.jsx`에서 공통 API를 제공하고 `src/app/ui.css`에서 기존 차콜 톤을 적용합니다. 모달과 선택창은 라이브러리의 키보드 조작·포커스 관리를 사용합니다. 파일 선택은 브라우저 기본 파일 입력을 Radix VisuallyHidden으로 감추고 라이브러리 버튼으로 엽니다. 본문 에디터의 콘텐츠 영역은 기존 방식이며 도구 버튼은 공통 UI를 사용합니다.

회원 리스트는 로그인한 등급에 따라 자동으로 구분됩니다. 운영자는 부운영자 이하의 등급 변경·직접 강퇴를, 부운영자는 일반·견습회원의 강퇴 요청만 할 수 있습니다. 본인·상위·동급 등급에 허용되지 않는 작업은 표시하지 않습니다. 두 등급 모두 요청 승인 목록에서 견습회원 가입 승인이 가능합니다. `memberCapabilities`의 같은 권한 계산을 서버 API와 Pages 미리보기에 적용하며 실제 변경 API도 권한을 별도로 검사합니다.

배너는 시안 제작 때 생성한 AI 일러스트입니다. 게임 로고는 PlayStation 공식 제공 이미지이며 비공식 팬 커뮤니티 디자인에서 사용했습니다. 이미지 권리는 각 권리자에게 있습니다.

로그인·개인정보 보안 보완과 검증 범위: [docs/security-review.md](docs/security-review.md).
